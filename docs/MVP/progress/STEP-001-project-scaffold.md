## 3. Implementation summary

The repository is an npm workspace. The only application is a minimal Next.js app in `apps/web`. It shows a placeholder home page and contains no character, passive-tree, or optimizer code.

Root scripts run typecheck, lint, unit tests, and the dev server. Vitest checks that `.env.example` lists the expected variable names and that every value is empty. Reserved folders exist for later domain and engine packages, but those folders only contain short README files.

pnpm is not installed on this machine, so the package manager is npm. That choice is recorded as D-009. Vitest is pinned to 4.1.11 because the initially installed 3.2.x release is covered by a moderate security advisory.

The GitHub repository https://github.com/AuTomaTheo/POE2-Buddy existed and was empty when checked. A local commit was created after this step was approved. Nothing was pushed.

## 14. Errors/issues encountered

### create-next-app reported the folder was not writable

- Symptom: `The application path is not writable` when the target was `apps/web` and that folder did not exist yet.
- Root cause: `create-next-app` checks write access before creating the directory. On this Windows setup that check fails for a missing path.
- Attempts: creating only `apps` was not enough.
- Final resolution: create `apps/web`, then run `create-next-app` with `.` as the target.
- Regression test added? No.

### pnpm is not installed

- Symptom: `pnpm` is not recognized.
- Root cause: the machine has Node.js 22.14.0 and npm 10.9.2 only.
- Final resolution: use npm workspaces. Recorded as D-009.
- Regression test added? No.

### Vitest 3.2.4 security advisory

- Symptom: `npm audit` reported moderate advisory GHSA-82fw-gwwq-j7x9 in Vitest 3.2.4 and `@vitest/mocker`.
- Root cause: the first install selected Vitest 3.2.4 from the `^3.2.4` range.
- Attempts: `npm install vitest@4.1.11 --save-dev` failed with `Cannot read properties of null (reading 'edgesOut')` in npm 10.9.2.
- Final resolution: pin `vitest` to `4.1.11` in `package.json`, then run `npm install --legacy-peer-deps`. A later `npm audit` reported 0 vulnerabilities. Tests still passed.
- Regression test added? No. The existing env example test was re-run on Vitest 4.1.11.

### ESLint deprecation warning

- Symptom: npm warned that `eslint@9.39.5` is no longer supported.
- Root cause: `eslint-config-next@16.3.6` depends on ESLint 9.
- Final resolution: left the Next.js-managed ESLint version in place. Forcing a newer ESLint could break `eslint-config-next`.
- Regression test added? No.

## 15. Security/privacy impact

`npm audit` after the Vitest pin reported no known vulnerabilities in the installed tree.
