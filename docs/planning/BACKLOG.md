# PoE2 Helper — Post-MVP Backlog

These ideas are deliberately outside the first MVP unless a roadmap decision moves them forward.

## Build analysis
- exact PoB-level DPS/EHP calculation coverage;
- gem/support optimization;
- weapon-set-aware scenario comparison;
- ascendancy optimization;
- attribute/resistance constraint solving;
- respec-cost planning;
- leveling trees for every level band;
- compare current build to target build.

## Gear
- advanced rare-item valuation;
- generated search filters for supported trade workflows if a documented safe API/mechanism exists;
- unique-item substitution analysis;
- breakpoint-aware gear constraints;
- import manually pasted item text;
- compare owned candidate items.

## Crafting
- mechanic-by-mechanic simulators;
- expected currency cost distributions;
- confidence intervals;
- target-affix planner;
- crafting path comparison;
- “stop/continue” decision helper;
- historical price-aware expected cost.

## User experience
- accounts and saved builds;
- build history;
- shareable analysis links;
- dark/light theme;
- mobile optimization;
- full passive-tree canvas rendering;
- accessibility improvements;
- localization.

## AI
- conversational explanation of optimizer results;
- ask “why this node?”;
- explain tradeoffs between two recommendations;
- summarize crafting risk;
- never permit AI to override engine values silently.

## Data/integrations
- automated safe game-data update pipeline;
- regression suite across patch snapshots;
- approved live GGG OAuth character import;
- richer official GGG APIs if/when PoE2 support expands;
- optional notifications for significant patch changes that invalidate saved builds.

## Explicitly not planned without policy/technical re-evaluation
- undocumented poe.ninja builds/profile/auth API;
- reverse-engineered private Path of Exile trade endpoints;
- botting/game automation;
- automatic in-game actions;
- storing or requesting user passwords.
